# Noisy Room Skill Tests

This directory contains the pytest-driven harness for testing the live `noisy:taskmd` skill through the Codex CLI.

## Run

```sh
uv run pytest
```

The default pytest suite invokes real `codex` commands. It is intentionally an end-to-end harness, not a contract-only unit test suite.

## Shape

- `tests/test_taskmd_skill.py` contains the first scenarios.
- `tests/harness.py` creates minimal fake workspaces, wires `.codex/skills/noisy:taskmd` as a symlink to the live skill, runs Codex, and validates outputs.
- `tests/schemas/verifier-result.schema.json` defines the structured result returned by the Codex semantic verifier.
- `/tmp/noisy-room-tests/` is generated by default.

Each behavior scenario uses a minimal workspace. It does not create `.git`, `README.md`, or `AGENTS.md` unless a future scenario needs them.

## Generated Runs

Run directories are created under:

```text
/tmp/noisy-room-tests/<scenario>-<id>/
```

Set `NOISY_TEST_RUNS_DIR` to use another generated-run root.

Successful runs are deleted by default. Failed runs are preserved with the fake workspace and command artifacts so failures can be inspected.

Set this to keep successful runs too:

```sh
NOISY_KEEP_TEST_ENVS=1 uv run pytest
```

## Current Coverage

- Discovery smoke test: verifies Codex sees `noisy:taskmd` through the fake workspace symlink.
- New task doc scenario: invokes `$noisy:taskmd --new` with `source.md`, validates the required markdown contract, then asks a Codex verifier for a structured semantic pass/fail result.
